# MCP implementation contract

Endpoint `/api/admin/mcp`, official `laravel/mcp` 1.x Streamable HTTP. No local MCP server. Bearer-only authentication: revocable SHA-256 token, admin role checked per request/tool, no session fallback. Exact scopes: `read`, `catalog`, `inventory`, `inventory:content`, `orders`, `orders:content`, `billing`, `settings`, `operations`. No wildcard or credential tools. CLI imports high-entropy token from stdin and outputs only record ID.

## Operation API (owned by coordinator)

Each domain has `App\Mcp\Domains\XDomain::tools(): array` returning `App\Mcp\Operation` instances. Each instance is a semantic named operation, never an arbitrary model/action/column dispatcher.

`new Operation(name: string, description: string, scope: string, schema: array, rules: array, read: ?Closure = null, snapshot: ?Closure = null, preview: ?Closure = null, apply: ?Closure = null, external: bool = false, destructive: bool = false)`.

- `schema` is JSON Schema **properties**, bounded types/enums/maxLength/items; `rules` are Laravel validator rules including required, nested allowlists. Unknown top-level properties rejected by shared adapter. Nested object rules MUST explicitly allowlist keys. JSON types checked against schemas before Laravel coercion. No arbitrary filters/sorts.
- Read closure receives validated payload array and returns safe structured array.
- Mutation snapshot closure receives `(array $payload, bool $lock)` and returns array containing state needed for stale detection, including raw sensitive state ONLY internally for keyed hashing. With `$lock=true`, acquire deterministic domain locks before rows (product before cards). Related state must be included. No external request in snapshot. Empty snapshot allowed only create operations where unique validation applies inside apply.
- Preview closure receives payload, returns safe public plan/eligibility/target IDs; NEVER writes business rows, dispatches events/jobs, or contacts mutation endpoint. Optional operational preview receipt writes are permitted. Return safe structured values; no secrets/card contents/messages/email bodies in preview. Fields containing secrets are represented as field names/presence only.
- Apply closure receives payload, returns safe public result including IDs and counts. Runs in DB transaction with snapshot locks unless `external=true`. External closures additionally receive a reviewed-state guard that must execute inside the canonical transaction before capturing immutable mail input or settling a payment. Use shared existing business services, never call Livewire. Catch sensitive provider/SMTP errors and throw `App\Mcp\OperationException('safe_reason_code')` (optional second array argument containing only safe details).
- External=true: durable receipt marked uncertain before external attempt, replay never sends again; result may be succeeded or indeterminate, not guaranteed delivery. Use for test email/resend. Payment recovery remains transactional through canonical service (provider query read-only); record post-commit dispatch caveat.
- Common fields added by coordinator: `dryRun` boolean default true, `reason` required string 1..500, `previewToken` string, `idempotencyKey` string 16..100. Fingerprints bind exact canonical payload incl reason+secrets but exclude those three protocol controls. No sensitive payload persisted. Preview expires in 10 min; same actor and token binding. Apply reuses exact payload; key collision fails. Audit stores metadata only. Read-sensitive output never audited; mutation results must be safe for persistence (no sensitive content).
- `App\Mcp\OperationException` extends RuntimeException; constructor `(string $reasonCode, array $details = [])`.
- `App\Mcp\Input` helpers supplied by coordinator: `page($query, array $p, array $columns): array` yields items,total,page,perPage,hasMore using page default1/perPage default25 max100. Domain owns safe column list. `paginationSchema()` / `paginationRules()` include page/perPage/search/archived (`active|archived|all`, default active). Query must implement search and archive filters if advertised. `ids(array)` sorts unique bounded selection, rejects duplicates, <=1000.
- Tests may call Operation closures directly while framework is landing. Auth guard is admin, use synthetic schema from existing FilamentAdminTest. Shared `Tests\McpTestCase` will provide admin fixture + migrations, `callTool(name,payload,scopes=null)` returning decoded MCP result structuredContent. Main coordinator will integrate all domains and HTTP tests.

## Ownership

Coordinator: Operation/Input/adapter/runner, auth+tokens+CLI+migration core, server/routes/config, shared test base, SDK smoke, aggregate matrix/report/CI. Domain contributors must not edit these files, composer manifests, routes or core migrations.

Catalog contributor: `app/Mcp/Domains/CatalogDomain.php`, inventory and coupon domain files, related shared services where necessary, corresponding tests; matrix `docs/shop-mcp-catalog-matrix.md`. Includes all products/categories/media/cards/coupons operations.
Orders contributor: `app/Mcp/Domains/OrdersDomain.php`, payments/refunds domains, related services, refund additive migration and tests; matrix `docs/shop-mcp-orders-matrix.md`. All orders/manual/bulk/delivery, provider query/recovery/refund distinctions, safe payment config. May extract PayResource::saveGateway into shared service and delegate UI method to it.
Settings contributor: `app/Mcp/Domains/SettingsDomain.php`, email and operational domains, tests; matrix `docs/shop-mcp-settings-matrix.md`. All settings groups/templates/test mail/ops summaries/audit/failed-job safe retry. Turnstile environment is server-owned; report read-only metadata + explicit unsupported setter, not arbitrary env writes. Restricted URL/host changes need deployment allowlist to prevent SSRF; coordinator config keys `shop_mcp.allowed_hosts` and `shop_mcp.allowed_origins`.

Before implementation, each contributor must inventory every scoped UI field/action and write its matrix. Follow TDD. Runtime `.tools/php/php` (PHP8.5.8 with intl), vendor PHPUnit. Set testing APP_KEY, APP_ENV=testing, DB_CONNECTION=sqlite DB_DATABASE=:memory: CACHE_DRIVER=array SESSION_DRIVER=array. No production/real notifications. No commits by contributors; coordinator commits exact tested result.
